# 第1块SAM3.1文字视频掩膜试验结论

2026年11月16日完成，仅处理第1块780帧，720×1280、30fps；没有补画。隔离分支exp/sam3-mask基于b69c266，不推送、不合并main。交付目录为 `/workspace/watermark-test/878ffd51/out-sam31/`。

结论：不建议进入补画。17.1秒左上蓝果图标主体基本覆盖，3.4秒动画主体有改善，但6.8秒大标的“蓝果”文字漏检，黄果品牌字仍不完整；logo提示误收公告栏实体标志，watermark轨迹混入对白字幕。合并v6保持严格并集，因此仍继承其人头和栏杆误盖。没有逐像素真值，不能用像素增加当召回率，也不能用纯SAM像素减少当误报消除量。

固定四个通用文字提示，置信度0.5；轨迹至少3帧、生命周期内出现比例≥15%，窗口120帧，容量16对象。没有手画框或影片特例。43条轨迹分为4层，独立检查单层最大7.828885%；合并基线共10层，每层保持≤20%。780帧输入、各层内容摘要、分层联合和最终严格并集均核验通过，v6移除像素为0。

第一次推理因官方16帧批量显存不足失败，保留日志后只做一次通用内存恢复：检测与后处理批量1，CUDA可扩展分配器，分辨率、语义阈值和面积保护未变。恢复成功，进程844.512秒；首次失败65.660秒，两次累计910.172秒，不含下载、安装、开发测试及等待。另记录一次SCP连接方式恢复，与模型错误恢复分开报告。

纯SAM相对v6新增9,421,899、移除27,884,892像素帧；与v6合并后新增9,421,899、移除0。合并结果相对v9新增2,486,915、移除9,306,143像素帧；这些差异混合了漏检、正确覆盖和误覆盖，不能直接排序质量。
