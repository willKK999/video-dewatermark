# 连续高置信度模型文字的模板缺失兜底

旧的冻结模型轨迹路径在文字高通模板相似度不足0.55时直接丢弃文字候选，不区分模型置信度。镜头切换、背景与尺度变化会使真实模型检测失去模板印证。

新增显式`--mask-source v8`，以冻结路径（实片v6使用的`v7`选项）为底。原图逐帧YOLO、共识模板、SAM支持与7像素邻域、图形外扩规则均保持旧值，拒绝混用增强、分区、翻转及覆盖合并。`recall`仍是独立实验选项，不在本轮启用。

仅对原路径未覆盖的文字，要求同镜头至少连续3帧置信度不低于0.8、同类双向重叠至少0.6、宽高变化不超过1.5倍，且与本输入旧模板路径已经确认的同类模型实例满足相同几何约束。参数集中在ModelTrackSettings。最后一项阻止把连续高置信度字幕直接当作新水印；这些锚点是本输入检测派生证据，不是影片固定坐标。只恢复直接观测的原模型框，不猜测相邻图标，不跨镜头拼接连续证据。恢复文字仅截取已确认原型内的文字锚点轮廓提示SAM（不使用完整品牌区域），仍受单轨及每层20%保护与摘要绑定校验。

ROI参考禁区保留c6cafe9的全体水印联合掩膜，施工仍仅作用于当前层。针对其他图层不得进入干净参考的合成测试保留。

单元测试覆盖连续检出恢复、孤立/低置信度/图形拒绝、镜头与缺帧边界、类别/位置/尺度跳变、字幕拒绝、旧覆盖不变、冻结检测路由和原SAM支持语义。实片必须先检查新增/移除像素及人物背景误覆盖，再决定是否补画；单元测试不代表实片通过。

首次实片准备中，新增文字的高通时域轮廓被背景噪声压制而不足16像素，未进入SAM或补画。唯一一次通用错误处理复用其已确认原型中的文字锚点轮廓，避免用无支持的矩形兜底；不扩展相邻图标。首次证据保留，恢复后仍须通过掩膜检查。
