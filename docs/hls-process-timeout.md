# 通用处理超时与原帧降级修复

新片v0的五块均在SAM子进程触发`worker.process.run`的900秒默认上限。该默认值不读取超时环境变量，也不按影片、帧数或水印数量调整。模板跟踪把739—840帧扩成411—460条轨迹、430—494次SAM初始化、约2.9万—4.0万组帧，且未做逐帧YOLO印证。MP4入口捕获异常后把缺失补画输出用原帧补齐，最终有文件而没有执行ProPainter。

本次保持`run`旧默认900秒与旧v7调用参数不变。新入口显式计算SAM工作量，包含实际初始化次数、需要解码的组帧、对象帧、抽样提示和图像像素数，预算下界900秒、上界7200秒。公式为加载90秒，加每次初始化8秒，加按像素缩放的组帧0.05秒、对象帧0.09秒、提示0.25秒；上下界和估算原值都记录，不只记录最终时限。超时异常携带阶段、上限、已用时与工作量，记录不包含环境值或完整命令参数。

原明文入口不再以原帧补齐缺失模型帧，阶段失败写入块号、具体阶段及错误码并重新报错。新单段入口统一捕获所有阶段失败，保留检查点，回退数为0，不生成伪成功结果。

新增的模型约束轨迹只在显式单段入口启用：位置来自专用YOLO逐帧观测；短缺口仅在可靠前后观测间有界插值。文字须得到本输入模型/共识品牌模板印证，字幕不直接作为水印。图形支持、颜色和提示均由本输入自动学习并作摘要绑定，不借用黄果坐标或资产。保留所有原始YOLO候选，模板峰不能单独建立新目标。SAM之后每遍维持20%面积保护，图层清单绑定检测摘要和逐帧掩膜摘要。

黄果影响分析：`worker.hls_v7`、SAM模型执行和调度、ProPainter模型执行、干净参考恢复、细节合成、原有配置均与`0e4dc7b`源码一致。旧v7不调用新单段模块；`vision.masks`默认`budget=None`时传给子进程的参数与原来一致，仍为900秒；新掩膜逻辑只在新schema存在时进入。已有成功路径的模型、权重、窗口、重叠、随机流程与像素运算没有变化。单元测试验证旧默认调用不创建新预算、不启用新检测分支。按kelin指示不实际回跑黄果，不以本次未执行的实验冒充其残留或闪烁实测结果。

本次只验证新片第1块0—24秒，含2秒右上下文，最多三轮。禁止运行其余四块或拼接整集，禁止实际回跑黄果。素材、检查点与验收文件均在仓库外；完整根因表和后续验证记录位于`/workspace/watermark-test/878ffd51/out-v1/中文报告.md`。
