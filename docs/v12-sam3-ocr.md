# v12纯掩膜：收紧OCR叠加层保护，增加无OCR对白保护

显式实验入口 `python -m worker.v12_masks {prepare,subtitles,merge} --help`，配置 `config/v12-sam3-ocr.json`。在v11基础上保留同一分支，不接入生产、不补画、不训练；v10/v11掩膜仅作对比，不作为候选并集。复用780解码帧、GPU OCR缓存、SAM3.1原始对象以及v11的3092张SAM2原始框提示，不重新运行模型。

## 叠加层证据

候选自身运动继续只用二值轮廓与模板。背景仍由候选外角点的LK对应与RANSAC仿射估计；局部LK窗口靠近边界不等于理想光学分层，不宣称完整透明层物理分解。

新增背景搬运中心误差校验：阈值为1.5原图像素加候选高度3%，补足“窄文字水平边缘平移后仍然重叠”的歧义。形状参考的累计遮挡还必须使归一模板IoU降至0.90以下，避免把累计位置漂移当作真实形状遮挡。实物证据仍需背景吻合、足够样本和前景遮挡同时成立。

OCR关联先经过v11几何检查，再检查候选相对OCR文字的真实位移差，中位差每5帧不超过2原图像素，至少跨0.5秒。即使文字关系通过，也只有候选全程相对屏幕固定，或形状稳定、运动平滑且相对背景独立，且不存在成立的实物/遮挡证据，才获得OCR保护。

背景形变与遮挡的实物证据不会再被单纯OCR邻近覆盖。固定位置仍要求整个生命周期框变化≤2像素；独立运动要求模板稳定比例≥75%、相对背景中心运动不一致比例≥50%。证据不足的候选保留并标为不确定，不伪称已获OCR保护。

## 不依赖OCR的字幕候选

仅用原图提取画面下部52%—94%的亮芯、低饱和文字样连通分量：亮度≥205、饱和度≤85，周边3像素暗描边/高对比（亮度≤105，比例≥16%）。按相对画幅的字符高宽、面积、字符数、行宽和水平居中聚成候选行。行宽18%—93%，中心距离画面中心≤20%，至少4个字符样分量。

用二值行模板跨帧关联，不识别内容。候选句级持续0.25—7秒、出现比例≥60%、基线抖动≤画高1.2%；同镜头其他句的同一字幕带或并发多行结构必须支持。模板变化会拆开不同句，短闪、长期实物文字、漂移的品牌/网址行会被时间/带一致性规则排除。所有相对位置、图像与时序阈值均在配置中。

`subtitle-independent/` 完全不读取OCR输入；`subtitle-ocr/` 是v11已有OCR补充；`subtitle-protection/` 是两者并集。最终SAM、OCR紧框下限及时域传播全部严格扣除此并集。每帧必须验证交集为零，但机器保护区不是人工字幕真值，仍需固定抽样和已知末段大图审查。

## 保护与核验

20%单对象与逐层上限不变；原始SAM2在紧框处理前也检查。`overlap_mae_limit` 不得超过35，原有HLS设置不修改；纯掩膜不产生或证明编码接缝指标。检测与输入摘要、图层逐帧摘要、0/255二值和最终严格并集保持。

第一次实测在审计序列化遇到NumPy布尔值，使用仓库现有 `json_native` 作一次通用序列化修正。保留失败目录，复用已完成字幕扫描和所有模型缓存，只重跑失败的合并阶段，不改语义参数。仍失败则停止，不自动调参。

证据入口 `scripts/v12_evidence.py` 只读原帧和掩膜，固定时点/已知ID只用于评价，不进入算法。报告必须区分真实改善、未验证边缘和新增误盖；模型缓存复用成本不能冒充冷启动或补画总耗时。
