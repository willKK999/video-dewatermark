# v10：SAM 3.1、OCR与通用过滤的纯掩膜入口

此实验不接入生产，不调用补画。基于 `exp/sam3-mask`，从 `fede39f` 的 `worker/experimental_detection.py` 移植OCR位置关联、镜头隔离、稳定文本检查和有界插值，删除DINO字段与实现。既不加载DINO，也不合并v6或任何旧检测联合掩膜。v9掩膜仅作为只读比较基线。

入口 `python -m worker.v10_masks {ocr,prepare,segment,merge}`，参数见 `--help`；配置 `config/v10-sam3-ocr.json`。新增OCR强制GPU，不允许悄悄回退CPU。复用本地OCR权重、已解码帧及SAM3.1原始对象；原始对象不修改。输入帧SHA256必须与SAM缓存来源一致。SAM2.1只运行新增OCR框提示。

## 规则

1. 文字：先按v9位置关联，按镜头分开，检查内容稳定比例、两秒生命周期与位置抖动。严格稳定文本作为全输入共识种子；另允许至少18次、跨3秒、长度至少3字符且主文本比例至少75%的长轨迹成为移动文字种子。共识相似度0.8。匹配共识的文字重新关联，允许移动和缩放，最低3次观测、0.4秒，最大缺口0.6秒；只在观测间插值，不向生命周期外扩展。不同识别变体仍需通过逐轨主文本门控，不能保证全部保留。
2. 非共识文字作为字幕/短暂文字保护区。保护只覆盖OCR实测框及向后一个采样间隔，且不跨镜头。框膨胀4像素，与SAM连通分量重叠占该分量至少5%时，只从SAM扣除重叠部分；混合轨迹其余水印区域保留。不按提示名或轨迹ID整条删除。未识别到的对白不能保证排除；这不是字幕真值。
3. 实物：每5帧、半尺寸Farneback光流，比较SAM掩膜内部中值流、24像素邻域环背景中值流，以及两帧掩膜质心位移。背景运动至少0.8原图像素、内部与背景流误差及质心与背景流误差均不超过1.8像素视为运动一致。至少4个有运动样本对，65%以上一致时拒绝整条对象。若一致样本发生至少35%面积缩小，视为遮挡/形变证据，允许一致比例降到50%后拒绝。面积缩小也可能源自分割变化，不能独立证明遮挡。静止背景无运动证据时保守保留；运动和遮挡不是完整语义分类器。
4. OCR框提示：交给本地SAM2.1图像预测器；保存原始SAM输出。输出限制在OCR框膨胀2像素内，同时将该膨胀框作为掩膜下限。因此本轮OCR最终支持实际等于框下限，能补字形缺口，但也覆盖字间和框内背景；不能宣称最终OCR支持是精确SAM笔画分割。单轨任何一帧超过20%整轨排除。
5. SAM短暂漏检：至少0.4秒、3次观测的轨迹，镜头内缺口不超过0.2秒才补，使用两端掩膜交集，补后再次扣字幕。只补内缺口，不外推，不跨镜头。OCR插值作为时域来源同时标记，来源允许重叠，不能相加当净新增。
6. 每对象与每层保持20%保护；按对象最大面积保守装箱。逐帧二值、形状、图层摘要、检测摘要与最终严格并集独立重读核验。所有阈值属于配置类/JSON，不包含影片、帧号、坐标或轨迹ID规则。证据脚本中的固定时间、审查ID只用于结果对照，不进入过滤。

## 低磁盘GPU依赖

Paddle GPU原生包较大。`scripts/v10_ram_native.py` 为可再生成的依赖建立内存原生库视图，通过Linux匿名内存文件描述符加载共享库；其余Python依赖复用已有环境。显式指定同一套CUDA 12库与cuDNN目录，防止加载不同环境的cuDNN子库。它不读取认证配置，不下载或搬运HF令牌。内存视图只在启动器存活期间有效，不能当持久安装。

## 证据与局限

`scripts/v10_evidence.py` 保存六时点四列对比、来源分解、二值大图、全长每2秒对白抽查与已知误盖对象前后对比。原始对象ID仅用于评价，不作算法条件。20%保护通过不等于语义通过；只有目检后才能说明具体问题是否改善。没有人工像素真值，不输出虚构精确率/召回率。完成一轮后停止，不自动调整门槛重跑。
