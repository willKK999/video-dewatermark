# 确认水印组的自适应边缘候选

本轮仅处理冻结确认组的边缘，不以新颜色候选重新确认水印，不修改旧掩膜内像素。所有规则与影片、坐标、轨迹编号无关，配置位于`config/v14-watermark-edges.json`。

每个有效种子连通分量独立计算搜索尺度：分量短边的15%加半帧运动曝光位移，上限为画幅短边6%；2像素只作为8位栅格抗锯齿接触尺度。外扩不是无条件膨胀，只保留有色差/局部alpha与边缘证据的候选。用于估计主色的彩色种子需高饱和度，并比背景环带更集中；中性半透明文字使用白色前景混合模型，不把混入的棕色背景当水印主色。

OCR框只限定笔画候选搜索范围，不作为矩形下限。彩色文字与中性文字分别按字高扩充搜索域；同组含彩色主色时，白色候选仅限中性文字域或抗锯齿接触域，避免白色网址的主色向背景栏杆传播。小于种子面积0.2%或5像素的孤立成分不参与外扩尺度估计，但旧掩膜原像素仍保留。

相邻取样间隔按0.25秒换算帧数，使用候选自身框的运动/缩放配准取得时域支持。另从旧掩膜之外的背景特征估计RANSAC部分仿射；只有背景配准支持比例≥70%、并高于自身配准10个百分点的完整候选分量才被该规则排除。背景配准特征不足或内点比例不足60%时不据此删除。快速缩放允许较低时域支持以免丢失动画瞬态，仍须单帧证据与保护区裁剪。

局部alpha拟合最小2%，按8位像素噪声与前景差值控制重建误差；这些是可配置的保守启发式，不能保证将水印与所有场景边缘区分开。尤其固定背景与固定覆盖层存在可辨识性限制，因此全帧交集检查之外必须核对实际大图。任何视觉回退都不得进入补画。

新增候选统一扣除冻结场景保护区和字幕保护区，再逐组和逐层核验20%上限。输出带原始数据/层哈希绑定，scene_added与subtitle_overlap必须为0，禁止静默丢弃旧掩膜像素。

补画仍沿用v6模型参数及35接缝门槛、三次接缝恢复。可选模型硬超时840秒，模型计算时每30秒记录存活心跳；此保护不改模型语义参数。最终视觉结果与实验数据见共享输出目录中文报告。
