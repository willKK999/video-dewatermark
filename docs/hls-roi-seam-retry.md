# 逐层 ROI 接缝恢复

逐层 ROI 每个时间窗先完整核验，接缝差异最大值不超过原配置（最高35）后才写入本层结果与覆盖记录。失败尝试不改写已通过窗口。模型始终读取冻结的上一层，扩展上下文不扩大本窗口的施工范围，每层20%面积保护保持不变。

`ROISettings.seam_retries` 集中控制恢复次数，默认3，允许0至3。原窗口失败后，依次增加一个重叠长度的前向上下文、两个重叠长度的前向与一个重叠长度的后向上下文、一个重叠长度的双向上下文并将模型内部子窗口缩短一半。上下文不能跨镜头；每次都重新补画和核验包括新增上下文在内的已完成重叠区。尝试耗尽仍抛出原错误，不回退原帧。

每次尝试的输入范围、模型子窗口、前向重叠帧数、最大差异、通过状态及耗时写入 `roi-report.json`，进度回调同步记录。真实显存不足只允许一次恢复，第二次仍失败即停止；其他模型错误直接停止。单任务超时根据输入帧数从900秒按工作量增加，不设整块实验预算。失败输入和预测保留；成功尝试删除临时裁块、保留报告。

合成测试覆盖：失败窗口不污染输出、恢复成功、全部接缝失败有界停止、显存不足只恢复一次、镜头边界与重试次数限制、原有图层顺序、面积保护与掩膜范围。
