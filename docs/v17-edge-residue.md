# v17：可信上下文与确认形状收边

v16 的45份阶段样本中，原始模型输出和参考回填后的确认掩膜内蓝色候选均为0；内侧羽化重新混入11,694个候选，全部位于内侧3像素带。该样本证据只解释抽样阶段，不能代替780帧整段目检，也不能将掩膜外候选全部认定为水印。

本轮将确认域中的源像素混合改为完整采用补画值。收边仅处理冻结确认组自身形状2像素窄带内、与该组源图主色一致的像素，不做全局颜色或亮度外扩。扣除已有场景/字幕保护和自动识别的低饱和高亮实物边界。新增像素与保护区交集须为0，原确认像素保持不变。派生掩膜绑定原图层摘要、逐帧输入输出掩膜摘要及配置，重新生成检测/图层清单。该方法仍可能漏掉无彩色、低饱和或无法由自身形状证明的外缘，未覆盖部分如实计入候选与目检。

配置在 `config/v17-edge-residue.json`：形状半径2，主色色相圆周距离12（OpenCV 0—179），源模板至少32个像素，饱和度与亮度下限60；收边主色在组内密度至少10%，且至少为8像素外环密度的2倍，否则不得扩展，避免灰白水印下的场景色被误作模板；这些值用于排除灰白高亮边并覆盖淡色细边，合成样例覆盖白衣、栏杆、公告纸边界。它们不是语义水印真值阈值。每次模型尝试合成和重叠混合之后，逐施工帧统计确认域及新增收边带的主色候选，允许像素数为0；没有放宽原先零残留要求。超限按v6的原始、平移、双向及短子窗口共四次尝试处理，仍未过则保留完整模型候选、标为未过。主色统计不能替代完整图标复检和目检；误报也不得静默计为通过。

可信上下文配置缺失必须失败；旧对象ROI、非空间逐层ROI及旧 `vision.inpaint` 模型入口明确禁用，开发用Telea保留。所有生产模型调用须使用空间ROI。模型输入掩膜读取全部确认水印并集并带3像素参考安全边界；独立自检再次读取冻结联合掩膜并独立计算形态/裁块/补边，与实际模型PNG核对，覆盖每次重试的所有上下文帧。输入契约错误不受继续未过块策略影响，保留原始错误码立即失败。

`CleanReferences` 的当前帧取点、参考帧追踪落点和误差环带都排除全部确认水印。重叠权重按已完成帧的排序位置计算，始终在0—1之间。装箱采用实际重试窗口峰值帧数；默认像素帧预算与空间配置一致。每次模型调用最多840秒，30秒心跳，自检写在本次工作目录。单遍20%和接缝MAE≤35不变。

稳定规划保留确认组与保护区链接，拒绝空/缺失掩膜，补齐缺省bindings，重新校验输出清单，跨文件系统链接失败改为复制。颜色对比工具按灰度掩膜取二维尺寸，拒绝缺少确认组，标签/帧数/抽样时刻取实际参数，输出逐帧CSV及收边带统计。

测试将旧已禁用接口的内部行为用例迁移至可信空间路径或替换为明确拒绝契约；保留底层合成器与光流测试。新增合成测试覆盖形状限制、同色远处不扩、高亮保护、零残留重试、缺配置禁止推理、独立期望构造、防四维shape、非前缀重叠、跨文件系统计划保留保护输入。
