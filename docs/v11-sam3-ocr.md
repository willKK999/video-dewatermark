# v11纯掩膜：形状和背景分离、字幕优先、跨窗口关联

独立入口 `python -m worker.v11_masks {prepare,segment,merge} --help`，配置 `config/v11-sam3-ocr.json`。沿用v10分支，默认不接入生产或补画；不导入DINO，不合并v6检测，v10最终掩膜仅作对比。

OCR复用内容摘要绑定的GPU识别结果，识别变体先按共识相似度归一再作逐轨稳定检查，保留原始文字。至少持续2秒的轨迹可在同镜头首尾各延伸0.6秒，用端部4个观测框线性拟合，最大残差不得超过文字高度25%。传播不跨镜头，不延伸短暂动画文字；每个新提示仍交SAM2.1。按帧与六位小数框内容精确匹配v10提示，完全相同的SAM原始输出只硬链接复用；其他提示才计算。缓存原文件不修改。

文字下限用原OCR紧框（零膨胀），SAM支持限制在额外1像素框内；最终所有来源都严格扣除OCR对白保护区。没有连通分量5%豁免，字幕优先于下限，保护区交集逐帧必须为零。无原始多边形时不伪造多边形；本轮使用紧框。

形状规则不再用掩膜内部光流代表候选自身运动。LK角点中心在候选联合掩膜膨胀区域之外提取、跟踪，终点也必须在候选之外。局部背景仿射用RANSAC估计；候选自身运动由二值轮廓/边缘决定，透明层下面的内部光流不再直接被当成候选自身运动。LK局部窗口仍可能接近轮廓边界，背景估计不等于理想的光学分层。

同镜头相同时间的高IoU候选及相邻窗口首尾候选可关联为一组，统一采样、统一累积背景变换和遮挡证据；不同镜头不合组。组内原对象仍分别受20%保护，不能靠关联或切分绕过上限。

OCR稳定文字相对候选位置/尺寸跨帧一致的组受保护；固定屏幕位置且模板稳定的组受保护；模板稳定、自身平滑且轮廓不跟随背景变换的组也受保护。固定位置检查整个生命周期的框坐标偏移不超过2原图像素，不用“相邻帧重叠高”代替全生命周期固定。

只有背景搬运后的候选轮廓吻合、背景运动样本至少4对且吻合比例≥60%，并存在前景遮挡证据，且没有覆盖层保护时才拒绝。背景吻合要求边缘匹配≥65%、观测轮廓对背景搬运轮廓的包含率≥75%。遮挡要求累积背景投影模板的内部缺失≥8%、最大连通缺失≥4%，并且缺失处被其他前景候选覆盖≥30%，或至少2个从候选外进入缺失区的特征点相对背景模型运动差≥3像素。无可靠背景或遮挡证据时保留。

上述遮挡是几何与外部特征代理，不是经过真值标注的人物遮挡分类器；真实结果必须目检，不保证所有场景实物都能排除。完全相同形状、相同轨迹的实物与覆盖层存在视觉歧义，不据稳定性单独判实物。

所有参数集中于配置。已知时点/轨迹ID只出现在只读证据脚本，不进入过滤。20%单对象和逐层保护、检测与逐帧摘要、严格最终并集保持。原始SAM2输出在紧框处理前也检查20%。

测试包括识别变体与双向边界传播、字幕最高优先级、透明图标OCR关系保护、无遮挡不得删除、固定/独立平滑运动保护、合成背景仿射及遮挡、跨窗口/镜头隔离、短对白排除、掩膜内部特征排除、配置和20%限制，以及慢移候选不能因相邻帧重叠高而被当成屏幕固定。
