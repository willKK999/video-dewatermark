# ROI模型掩膜范围修复

ROI规划已按互斥图层、轨迹和时间窗分组，但模型输入曾使用裁块内所有未完成的联合掩膜，重新带入其他图层。联合掩膜可以超过20%，不能作为单遍模型输入。

模型输入现收紧为当前任务所属掩膜减去已完成像素；上下文没有施工目标时输入空掩膜。保留全部目标、同源基线逐像素覆盖检查与最终ROI覆盖检查，不通过删掉基线覆盖来避开保护。每遍模型和贴回施工仍各受20%原帧面积约束，不缩放、不回退原帧。失败详情记录任务、帧、ROI、像素数及比例；任务报告记录最大模型掩膜原帧占比。

合成测试覆盖两层各低于20%、裁块内联合超过20%的场景：每次模型只收到本层目标，最后联合覆盖完整，背景和源缓存不变。另验证真正超限仍拒绝并附定位信息，以及已完成像素不再进入模型。

本次实测范围仅为用户指定输入的第1块第3轮；检测与SAM检查点按已有内容摘要校验后复用。原第2轮失败定位和第3轮原始报告留在仓库外的 out-v3，最终结果以其中的中文报告为准。禁止追加第4轮，不运行其余块、整集或黄果。
