# 原生ROI逐层补画与背景上下文

新增显式参数 `--roi-layered --roi-context-ratio 0.75 --roi-min-context 96`，与 `--mask-source v7 --inpaint-mode roi` 配合使用。原有默认路径保留，以便对照已有结果；新路径未获整块验收通过。

新路径严格按已验证图层清单顺序执行，当前层冻结上一层的完整输出作为输入。同层窗口不得读取当前层已施工画面；跨层重叠像素仍须重新补画，不由全局覆盖记录跳过。每层、每帧保留20%原帧面积保护。背景按目标包络最大边长的比例外扩，并设置像素下限、对齐8像素；仅改变原生裁块范围，掩膜不膨胀、不降分辨率。

时间参数使用 `HLSSettings` 的36帧窗口、8帧重叠，以及v7低内存模型参数 neighbor_length=6、ref_stride=20。模型保持原生半精度。每窗空间包络来自本层窗口内真实掩膜；同镜头参考纹理由上一层输入及本层掩膜构造。重叠输出按原v7权重混合，差异上限仍为35。空掩膜区域保留上一层画面属于有效输入传递；有施工目标但模型缺帧、改变几何或失败时直接报错，禁止原帧补齐。任务、图层、耗时和失败检查点均保留。

合成测试覆盖跨层同像素再次施工、上一层画面传递、同层窗口输入冻结、窗口重叠混合、时间模型参数、掩膜外不变、20%面积拒绝、缺帧失败检查点。完整Python测试323通过、12跳过、0失败；Go测试通过。数据库及真实存储集成测试未运行。

本次短窗实验在600秒硬预算下超时，仅完成两种组合的三个短窗，第三组合未完成，停止整块运行。两种已完成组合在部分静态样本消除了旧版左上残留，但浮动大标和半透明图标仍残留；不存在已验证的最佳组合，也没有整块v5交付。实验并未完全隔离时间参数、参考纹理和图层语义的影响，不能宣称根因已定位。诊断脚本、媒体和完整证据均存于仓库外，不进入生产流水线。
