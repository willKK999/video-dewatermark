# v13c：检测组与补画空间区域分离

v13b笔画版掩膜冻结复用，不重跑OCR/SAM，不改变最终掩膜或图层语义。`config/v13-spatial-roi.json`只控制施工域规划：掩膜适度膨胀后提取连通区域，远区域独立，近邻仅在预算内合并。超过预算的连通区域递归空间二分，逐像素验证原掩膜恰好分配一次。

面积上限708480像素，来自此前720×984原生裁块的已执行记录；像素帧预算19229184，来自此前36×624×856的可行输入规模。配置按面积而非影片位置工作，同时计入一次恢复可能增加的前向上下文。不用按检测组外接框强行覆盖整幅画面，也不降分辨率或缩小最终掩膜。上下文比例0.75、最小96像素保持历史值。

新引擎`worker.roi_spatial_layers`只在独立任务提供空间配置时启用。模型读取冻结的上一层；输入裁块中的当前层完整掩膜保留，写回只限当前施工域。覆盖与时域重叠按像素记录；相邻区域已完成像素若落入模型上下文，也检查预测差异，35接缝阈值不变。失败尝试先暂存，不会提交部分结果或回退原帧。

`scripts.spatial_roi_preflight`在模型运行前检查全部时空窗口的掩膜摘要、20%面积保护、空间覆盖及裁块/像素帧预算。入口`scripts.frozen_mask_inpaint --spatial-config ...`复制显式配置，沿用v6模型配置和一次真实错误恢复预算。

运行目录与旧失败结果分离，保留旧v13/v13b全部材料。监控检查启动PID、子任务结果和退出状态，预检600秒、补画10800秒，监控有总期限；不会等待不存在的补画进程。

新增测试验证远区分离、大区拆分、预算、像素归属、掩膜外原像素和多区域覆盖。完整Python424通过、12跳过，Go通过。真实运行的最终结果以用户指定目录的中文报告为准；单元测试及ROI预检不代表成片验收通过。
