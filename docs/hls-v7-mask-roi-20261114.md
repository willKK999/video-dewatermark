# v7检测掩膜与ROI补画组合

单段入口增加 `--mask-source v7`，默认仍为 `current`。与 `--inpaint-mode roi` 和 `PROPAINTER_FP16=true` 组合使用。v2/v3代码保留。

`worker/model_tracks_v7.py` 冻结自5f9cdd9，仅增加NumPy数值JSON序列化适配；`scripts/hls_candidates_v7.py` 保留同提交的逐帧YOLO调用。v7策略拒绝后续检测增强、切片、翻转和覆盖参考合并，避免改变候选或掩膜。SAM仍使用同样的镜头/生命周期调度；没有预计算轨迹时调度与v1相同。掩膜使用原始支持与SAM在7×7膨胀支持内的交集，不调用透明度自适应扩展。轨迹及图层20%保护保持。

独立工作目录记录 `mask-policy.json`，禁止把另一策略检测缓存当作v7结果。`--mask-reference` 可指定同源历史工作目录；检查源摘要、帧范围、逐帧源摘要、掩膜摘要和图层清单，再逐帧输出像素覆盖率、IoU、缺失和新增像素。仅完全等价才进入补画，比较报告即使失败也保留。

ROI继续使用各任务所属图层/轨迹像素，排除已完成像素；不混入其他图层，模型掩膜原帧占比仍不得超过20%，最终联合覆盖必须完整，不允许失败回退原帧。

新增合成测试覆盖原始掩膜公式、像素不等价阻断、源绑定错误和单目标20%保护。既有ROI测试覆盖跨图层污染、完整覆盖与原生几何。
