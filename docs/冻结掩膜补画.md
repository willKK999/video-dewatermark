# 冻结掩膜的独立补画

`scripts.frozen_mask_inpaint` 直接复用已确认的 `frames/`、`masks/`、`layers.json` 和 `detections.json`。输入解码帧必须具备原有 `frames-binding.json`，并与历史报告的源摘要一致。入口逐帧核验图层摘要、20%面积保护，以及各层严格并集等于最终掩膜；不运行检测、分割或改写掩膜。

`--baseline` 指定历史报告，原样读取其中的逐层 ROI 配置，并要求当前窗口、重叠与历史值一致。接缝上限固定35、每层面积上限固定20%；原生分辨率，禁止联合纹理投影。模型调用仍使用现有 ROI 引擎及其固定 ProPainter 参数。输出 H.264，CRF沿用现有设置，原音轨仅复制并校验压缩内容。

一次真实错误只允许使用现有引擎的一次通用恢复；同任务再次失败立即停止。历史 `seam_retries` 保留在冻结配置中，外层错误预算优先限制实际恢复次数。失败保留 `failure.json`、`run/roi-report.json` 和临时尝试，不编码不完整图层，不使用原帧回退伪造成片。

为节省空间，仅在完整图层完成之后移除本次运行中不再被模型读取的更早层 PNG。源输入、冻结掩膜、历史成片及报告不在清理范围内。运行目录不支持隐式续跑，以免将失败暂存结果当成完整检查点。
