# 稳定层与可信上下文排除

冻结的最终掩膜像素不变。先计算所有确认对象的逐帧真实并集峰值；若并集与模型安全边界后的排除区均不超过20%，将完整生命周期中的所有部件固定在同一层。此策略不使用基础桶编号作为对象身份，不会在镜头或模型窗口内部迁移部件。任一帧超限或输入为空即报错，不能改用不排除其他层的旧流程。

`config/v16-trusted-context.json`集中设置模型角色。模型排除区是全部确认水印并集加参考安全边界；本层施工域仍是原形状掩膜与ROI ownership的交集。模型保存帧、参考回填与羽化结果只在施工域内提交，掩膜外像素不变。ROI最小512、上下文96、裁块/像素帧显存预算及v6模型参数不变。

3像素仅用作模型可信区安全边界，与既有`CleanReferences`供体排除的边界一致，用于阻断插值/抗锯齿边缘被视作已知背景；不是水印检测外扩，也不增加最终施工像素。它受同样20%约束。仅并集合并而不加安全边界的首份运行被主动停止，其原始模型阶段仍有蓝色，证据保留；没有将其视为已完成成片。

每个任务、每次恢复、每个上下文帧都读取实际落盘的模型掩膜PNG，与独立构造的全部期望排除区逐像素核对，再校验施工域从属关系和面积。任何漏排除在启动模型前触发`UNTRUSTED_CONTEXT`；记录`层输入自检.json`。该自检针对冻结确认集合及可信区边界，不等于对所有未检测真实水印的语义召回率证明。

每次完整推理选择最多3个真实活动施工帧，保存ProPainter原始输出及排除/施工掩膜。首个样本另保留来源、参考回填后及羽化后结果，未经过窗口混合与最终施工域回写。所有模型尝试的指标、抽样和文件摘要独立保存；失败任务仍沿用v6三次接缝恢复，耗尽后选完整的最佳尝试并明确标未过，无完整候选禁止原帧伪造成片。

不放宽接缝MAE 35、每层20%或显存预算。模型调用有840秒硬时限和30秒存活心跳，监控有PID/退出状态、总期限与840秒无输出中止检查。实验素材及图片不进入Git。
